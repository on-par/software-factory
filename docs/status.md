PR risk receipts show the overall tier and matched rule reasons without paths. Walkthrough verification reports checker and manual evidence counts without plan claims. PR Proof reports TypeScript and non-test net lines (added minus deleted) against the PR base; non-test excludes test files and test or fixture directories. Failed diff counts are unavailable.

A run persists its resumable state (rework counters, handled reviews, status, spec summary) in a factory-owned hidden comment on its open PR and restores it on a fresh clone, so disposable hosts can continue a run with only `GH_TOKEN` (ADR-0174). Only the factory's own identity, a matching digest and the right work key are trusted.

See the [README](../README.md) for Quick Start, and [agents.md](agents.md) for the supported coding agent CLIs.

Hosted code-health CI is checked on the base before landing. Failed CI leaves PRs open; pending CI waits up to 30 minutes. A failed base descended from a recorded merge pauses merges until hosted CI is green, emitting `red-main` once and `red-main-cleared` on recovery. A required check that is `skipped` or `neutral` counts as passing, as in GitHub branch protection. Local base checks remain an additional gate.
