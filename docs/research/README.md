# Research notes

Discovery and research notes behind On PAR Dev's Software Factory design decisions. The ADRs in
[`docs/adr/`](../adr/README.md) are the decisions of record; these notes are background.

Some notes cited here by issue number are internal and are not published in this repo: the sandbox
posture audit (#618), the AI subscription terms review, the deployment automation audit (#624), the
cloud provisioning guardrails (#627), the small-model factory harness study, the local-only baseline
run (#164) and the SHIP phase breakdown (#1328). Where a note below refers to one of them by path,
read it as a pointer to that internal note.
