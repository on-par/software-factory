# @on-par/factory-cli

The `factory` command: ships verified GitHub issues via boss-worker-checker orchestration.

Part of [Software Factory](https://github.com/on-par/software-factory), a multi-agent factory that ships verified work autonomously. Most users want the CLI, [`@on-par/factory-cli`](https://www.npmjs.com/package/@on-par/factory-cli); the other packages are its building blocks.

## Install

```bash
npm install -g @on-par/factory-cli
factory --help
```

Requires Node.js >= 24, `git`, and an authenticated GitHub CLI (`gh`). See the [Quick Start](https://github.com/on-par/software-factory#quick-start-5-minutes) for model CLIs and first-run setup.
